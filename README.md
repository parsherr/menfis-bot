Eski bir botumun resmi websitesi! Bu proje, bir anime partner botunun web platformudur ve kullanıcıların dökümantasyona erişmesini, sponsor bilgilerini görüntülemesini ve Discord topluluğuna katılmasını sağlar.  

## 🌟 Özellikler  

- **📚 Dökümantasyon Sayfası:** Menfis Bot'un tüm işlevlerine ve kullanım detaylarına kolayca ulaşabilirsiniz.  
- **🏠 Ana Sayfa:** Bot hakkında genel bilgiler ve botu kullanmaya başlamak için rehber niteliğinde bir giriş sayfası.  
- **🤝 Sponsor Sayfası:** Projeyi destekleyen sponsorların listesi ve sponsor olma seçenekleri.  
- **🔗 Yönlendirme Linkleri:** Discord sunucusuna katılma ve diğer ilgili kaynaklara erişim sağlayan hızlı bağlantılar.  

## 🛠️ Teknolojiler  

Bu web sitesi şu teknolojiler kullanılarak geliştirilmiştir:  

- **React**: Kullanıcı arayüzü oluşturma.  
- **TypeScript**: Daha güvenli ve okunabilir kodlama deneyimi için.  
- **Next.js**: SEO dostu, performanslı ve hızlı bir React framework'ü.  
- **Tailwind CSS**: Hızlı ve esnek bir şekilde modern tasarımlar oluşturmak için CSS araçları.  

## 🚀 Projeyi Çalıştırma  

Projenin yerel ortamda çalıştırılması için şu adımları izleyin:  

1. **Projeyi Klonlayın:**  
   ```bash  
   git clone https://github.com/parsherr/menfis-bot.git  
   cd menfis-bot  
   ```  

2. **Gereksinimleri Yükleyin:**  
   Node.js ve npm yüklü olduğundan emin olun, ardından:  
   ```bash  
   npm install  
   ```  

3. **Geliştirme Sunucusunu Başlatın:**  
   ```bash  
   npm run dev  
   ```  
   Tarayıcınızda `http://localhost:3000` adresine giderek projeyi görüntüleyebilirsiniz.
